About ParkWise

Smart parking project for Antwerp. Sensors + AI + Simple UI.

Our Story

We're building a scalable parking assistant: ground sensors detect occupancy, the backend aggregates readings, and a prediction model estimates busy hours per zone. This demo uses sample streets while the database and ingestion endpoints are being finalized.

Technology Stack
Hardware
Magnetometer + distance sensors (Arduino) over GSM
Backend
Spring Boot, JPA, PostgreSQL
Frontend
Thymeleaf, Bootstrap, Leaflet
